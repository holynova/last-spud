# 地牢幸存者 · 优化路线图

> 基于当前代码实现（`js/` 共 10 个模块）的分析清单。按「性价比」分四档，每条标注涉及的模块。
> 勾选框用于跟踪进度：`[ ]` 未开始 / `[x]` 已完成。

## 一、性能与工程（性价比最高）

- [x] **空间网格碰撞** `game.js` / `entities.js`
  敌人分离是 O(n²)（230 只敌人 ≈ 每帧 2.6 万次距离检查），子弹命中也是全量遍历。后期弹幕 + 怪潮时的主要掉帧来源。
  方案：按 100px 网格分桶，分离与子弹碰撞只查相邻格，可降到近似 O(n)。

- [x] **HUD 增量更新** `ui.js`
  技能栏冷却遮罩每帧重建 innerHTML（`scd` 高度变化即整段重写 DOM）。
  方案：建槽时缓存元素引用，之后每帧只改 `style.height` 与等级角标。

- [x] **音效节点节流** `audio.js` / `weapons.js`
  喷火杖 0.07s 一发 = 每秒 14 个 oscillator/gain 节点，叠加命中音效后高频战斗可能出现音频毛刺。
  方案：同类音效加 30~50ms 最小间隔；连续命中合并为一枚音量更高的音。

- [x] **移动端支持** `main.js` / `index.html` / `css`
  目前仅键盘操作。
  方案：触屏虚拟摇杆（左半屏拖动 = 移动方向），HUD 与面板做小屏布局适配。

## 二、战斗反馈（体感提升最明显）

- [ ] **Boss 顶部血条** `game.js`
  血条目前画在 Boss 头顶，Boss 走出屏幕就不可见。
  方案：Boss 存活时在屏幕顶部绘制固定血条 + 名字。

- [ ] **连击系统** `game.js` / `ui.js`
  击杀计数 + 连击条（3 秒无击杀清零），每 50 连击掉一个宝箱（随机武器 / 道具 / 材料雨）。
  价值：给"聚怪一波清"的走位提供额外奖励动机。

- [ ] **精英词缀** `data.js` / `entities.js` / `game.js`
  精英目前只是数值放大，缺乏变化。
  方案：随机词缀池——迅捷（+40% 移速）/ 吸血（攻击回血）/ 尸爆（死亡自爆）/ 石肤（减伤 50%），各配一个外框颜色与头顶小字。

- [ ] **可破坏木桶** `game.js` / `weapons.js`
  场景装饰已有箱子/木桶（`decor`），但不可交互。
  方案：给装饰物加血量与碰撞子弹的判定，打碎掉 2~4 材料；爆炸波及也能打碎。成本极低。

- [ ] **低血量反馈** `main.js` / `css`
  血量 < 30% 时屏幕边缘红晕 + 心跳音效，随血量降低加强。

## 三、构筑深度（长线可玩性核心）

- [ ] **武器流派标签** `data.js` / `ui.js`
  道具目前是纯数值堆叠，没有 build 身份。
  方案：武器打标签（火系 / 电系 / 近战 / 投掷），新增协同道具「火系伤害 +25%」「投掷物数量 +1」「近战击杀回 1 血」等，形成流派：喷火杖 + 火伤流、飞刀 + 投掷物 + 攻速流。

- [ ] **召唤系武器** `entities.js` / `weapons.js` / `data.js`
  幸存者品类的高价值功能。
  方案：新增「精灵图腾」——召唤 1~2 个友方单位自动索敌（复用 Enemy 类改阵营），素材可用 tiny-dungeon 的精灵/老鼠图块染色。

- [ ] **角色初始技能** `data.js` / `entities.js`
  当前技能全靠升级随机，角色个性只在数值。
  方案：狂战士 = 狂化 Lv1、铁卫骑士 = 圣盾术 Lv1、小学徒 = 闪电链 Lv1、冒险家 = 无初始但升级时技能卡权重更高。

- [ ] **技能 5 级觉醒（质变）** `skills.js` / `data.js`
  满级后附加特效：震荡波留火径 / 闪电链眩晕 0.5s / 烈火结界跟随移动 / 荆棘领域减速翻倍。给满级一个追求。

- [ ] **事件波次** `game.js`
  每 4 波随机事件：宝箱怪（打死掉 30 材料）/ 血月（敌人翻倍、掉落翻倍）/ 泥沼（双方减速）。在现有 `startWave` 加类型分支即可。

## 四、元游戏与长线

- [ ] **局外解锁** `game.js` / `ui.js`
  用累计材料作为元货币，局外解锁新角色 / 新武器进入商店池。存档基础设施（localStorage）现成，是重复可玩性最大的单项投资。

- [ ] **多地图换皮** `game.js` / `data.js`
  Kenney 素材包里还有石砖 / 深色地砖，每 4 波换一张图（地面 + 装饰 + 边界墙换色），几乎零成本。

- [ ] **本局战斗统计** `weapons.js` / `ui.js`
  暂停面板新增「各武器伤害占比」。在 `dealDamage` 加来源计数即可，构筑玩家很需要这个数据来验证流派。

- [ ] **图鉴页** `ui.js` / `data.js`
  主菜单入口，展示敌人（含词缀）与武器说明，数据全部现成，纯 UI 工作。

## 建议实施顺序

**第一轮（手感与性能）**：空间网格 → Boss 顶部血条 → 连击宝箱 → 精英词缀 → 可破坏木桶。
前者解决性能后顾之忧，后四项都是「低成本、高感知」。

**第二轮（构筑版本）**：流派标签 → 召唤武器 → 角色初始技能 → 技能觉醒。

**第三轮（长线版本）**：局外解锁 → 事件波次 → 多地图 → 统计与图鉴。
